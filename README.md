# meatball

keep the ball rolling

Meatball is an OpenBoa project to build a supervisor for delegated software work. A product owner gives it a goal, and the supervisor turns it into reviewed specifications, assigns isolated work to agents, and verifies the combined result before handing it back.

See [Contributing](CONTRIBUTING.md) for branch names, pull requests, and the repository checks. Report security issues through [private vulnerability reporting](SECURITY.md).
